# Windows 11 Virtual Machine Lab

## Overview

This project documents the installation of Windows 11 in a virtual machine environment.

The Windows 11 ISO was created using the official Windows 11 Media Creation Tool and then used to install Windows 11 inside a virtual machine.

## Objectives

- Create a Windows 11 ISO using the Media Creation Tool.
- Create and configure a virtual machine.
- Install Windows 11 in a virtualized environment.
- Gain hands-on experience with operating system installation and virtualization.
- Build a foundation for future Windows and networking labs.

## Tools & Technologies

- Windows 11
- Windows 11 Media Creation Tool
- Windows 11 ISO
- Virtual Machine
- Virtualization

## Practical Steps

1. Downloaded the official Windows 11 Media Creation Tool.
2. Used the tool to create a Windows 11 ISO file.
3. Created a new virtual machine.
4. Configured the virtual machine for Windows 11.
5. Mounted the Windows 11 ISO.
6. Installed Windows 11 successfully inside the virtual machine.
7. Verified that the operating system was running correctly.

## Skills Practiced

- Operating System Installation
- Virtual Machine Configuration
- Windows 11 Setup
- ISO Creation and Installation
- Virtualization Fundamentals
- Basic IT Support Practices

## Future Improvements

This lab will be extended with additional Windows administration and networking exercises, including IP configuration, network troubleshooting, connectivity testing, and communication between virtual machines.

## Conclusion

This project provided hands-on experience installing and configuring Windows 11 in a virtualized environment and serves as a foundation for future IT Support, operating system, and networking labs.
